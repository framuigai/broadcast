# Reference Set Changelog

Every change to anything under `eval/references/` is recorded here.

A reference set is the measuring instrument. Changing it silently invalidates every
number previously reported against it — so a change is only ever made when a reference
transcript is *genuinely wrong*, and it requires re-baselining every affected figure.
